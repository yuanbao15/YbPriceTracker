# 图标说明

此目录需要放置 Chrome 扩展的图标文件。

## 需要的图标尺寸

- `icon16.png` - 16x16 像素
- `icon48.png` - 48x48 像素
- `icon128.png` - 128x128 像素

## 图标设计建议

1. **主题**：购物车、价格标签、图表等与购物和价格相关的元素
2. **颜色**：建议使用蓝色渐变（#667eea → #764ba2），与扩展 UI 保持一致
3. **风格**：简洁、现代、易识别

## 获取图标

你可以：

1. **使用在线图标生成器**：
   - https://favicon.io/
   - https://www.canva.com/

2. **使用免费图标资源**：
   - https://www.flaticon.com/
   - https://icons8.com/

3. **自己设计**：
   - 使用 Figma、Sketch 或 Adobe Illustrator

## 临时解决方案

如果你暂时没有图标，可以使用以下方法：

1. 创建一个简单的纯色图标
2. 或者暂时注释掉 `manifest.json` 中的图标配置

注意：没有图标可能会导致扩展在 Chrome 工具栏中显示为默认的拼图图标。
